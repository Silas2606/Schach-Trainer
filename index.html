    Fortschritt in GitHub speichern

    Wenn du verbunden bist, speichert die App deinen Lernstand und deine Partien-Auswertung automatisch als Datei fortschritt.json im Branch fortschritt deines Repositorys. So hast du denselben Stand auf jedem Gerät.

    So erstellst du den Token (einmal pro Gerät)

    1. Öffne auf GitHub Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Bei Repository access wählst du Only select repositories und nur dieses Repository.
    3. Bei Permissions → Repository permissions setzt du Contents auf Read and write. Sonst nichts.
    4. Token kopieren, oben einfügen, auf Verbinden und laden klicken.

    Der Token bleibt nur in diesem Browser gespeichert und wird nie ins Repository geschrieben. Ist dein Repository öffentlich, kann jeder die Datei fortschritt.json lesen. Sie enthält nur deinen Lernstand und deine Eröffnungsstatistik.
